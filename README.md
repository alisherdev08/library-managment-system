# 📚 LIBRARY MANAGMENT SYSTEM

A simple console-based Library System built with Java to practice core **Object-Oriented Programming (OOP)** concepts and clean project structure.

---

# ✨ FEATURES

- 📖 Add and manage books
- 👤 Manage library users
- 🔄 Borrow and return books
- 🗂 Store data using Java Collections
- 🧩 Clean separation of logic using layers

---

# 🧠 OOP concepts practiced

- **Encapsulation**
- **Abstraction**
- **Object Composition**

---

# 🏗️ PROJECT STRUCTURE

```
src/
 ┣ app/
 ┃ ┗ Main.java
 ┣ entity/
 ┃ ┣ Book.java
 ┃ ┣ BorrowRecord.java
 ┃ ┗ Student.java
 ┣ repository/
 ┃ ┣ BookRepository.java
 ┃ ┣ BorrowRecordRepository.java
 ┃ ┗ StudentRepository.java
 ┗ service/
   ┣ BookService.java
   ┣ BorrowRecordService.java
   ┗ StudentService.java
  
```

---

# ⚙️ TECHNOLOGIES

- **Java**
- **IntelliJ IDEA**
- **Java Collections Framework**

---

# 📌 PURPOSE of the PROJECT

This project was created to strengthen understanding of:

- Java fundamentals
- OOP design
- Code organization
- Basic application architecture


  This project demonstrates encapsulation through private fields and abstraction through service-repository separation. Other OOP principles were not forced because the domain did not require inheritance or polymorphism.
